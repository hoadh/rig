# Devlog

Use the `devlog-writer` subagent to explore the memories and recent code changes, and write some devlog entries.
Devlog entries should be concise and focused on the most important events, key changes, impacts, and decisions.
Keep devlog entries in the `./docs/devlog/` directory.

**IMPORTANT:** Invoke "/project-organization" skill to organize the outputs.
